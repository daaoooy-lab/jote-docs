## 프로젝트 개요

개인 프로젝트 **Jote** — 메모 사이트로 시작.

### 프로젝트 이름
**Jote**는 **Jot**과 **Note**의 합성어다.
- Jot: 순간적으로 떠오른 생각을 짧고 빠르게 끄적여 남긴다는 뜻의 동사
- Note: 정리되고 구조화된 기록, 메모를 뜻하는 명사/동사

가볍게 끄적이는(Jot) 순간의 기록이 정리된 지식(Note)으로 이어지는 메모 서비스라는 의미를 담아 이름을 지음.

<br/>

### 아이디어 발산 과정
원래는 단순히 직접 쓸 개인 메모 사이트를 만들 생각이었음. 만드는 김에 개인 프로젝트로 공부하며 진행하면 좋겠다고 판단함. 다만 "메모 사이트"라는 주제 자체가 너무 단순해서 어떤 걸 더할지 고민하다가, 기존 메모 서비스들과는 다른 차별화된 특징을 가진 메모 사이트를 만들어보자는 방향으로 잡음.

<br/>

**목표**
- Next.js를 중심으로 최신 프론트엔드 기술 학습
- AI Agent 및 LLM 기반 기능 구현 경험
- 프론트엔드, 백엔드, AI를 분리한 아키텍처 설계 경험
- 기획부터 설계, 개발, 배포까지 전 과정을 직접 경험
- 개발 과정과 기술적 의사결정을 문서화하여 학습 기록으로 남기기

<br/><br/>

## 기본 메모 기능

- 메모 작성 / 수정 / 삭제
- 리치 텍스트 에디터
- 이미지 첨부
- 파일 첨부
- 체크리스트
- 코드 블록
- Markdown 지원
- 자동 저장
- 버전 히스토리

> 참고
> - 리치 텍스트 에디터 선택은 이후 AI 기능(문장 다듬기, 이어쓰기 등) 연동과 밀접하게 연관됨 (Tiptap/Lexical 등 AI 삽입이 쉬운 에디터 고려)
> - 버전 히스토리는 구현 난이도가 상대적으로 높아 MVP에서 후순위 후보
> - 자동 저장은 에디터/백엔드 API 설계에 영향을 주므로 초반에 방향 확정 필요

<br/><br/>

## AI 기능

### AI 작성 지원
- 제목 자동 생성
- 태그 자동 생성
- 카테고리 추천
- 메모 요약
- 문장 다듬기
- 맞춤법 교정
- 번역
- 이어쓰기 / 아이디어 확장
- 음성 메모 → 텍스트 변환 + 구조화
- 이미지/스크린샷 캡처 → OCR + 자동 요약

<br/>

### AI 메모 관리
- 관련 메모 추천
- 메모 자동 분류
- 중복 메모 탐지
- 유사 메모 병합 제안
- 지식 그래프 생성
- 메모 간 링크 자동 생성
- **의미 기반(자연어) 검색** — 키워드 매칭이 아닌 임베딩 기반 검색. AI Agent(메모 기반 채팅)의 기반 기술(RAG)이 되는 핵심 기능
- 오래된 메모 재발견 — 현재 작성 맥락과 관련된 과거 메모를 자동으로 다시 표면화

<br/>

### AI Agent
- 내 메모 기반 AI 채팅
- 특정 주제 정리
- 여러 메모 통합 요약
- 질문 답변
- 실행 계획 생성
- TODO 추출

<br/><br/>

## 추가 기능 브레인스토밍

### 정리 및 검색 (비-AI 기본)
- 즐겨찾기 / 고정(pin)
- 폴더 · 노트북 구조 (계층형 정리)
- 필터링 (날짜, 태그, 첨부파일 유무)
- 키워드 전체 검색
- 최근 열어본 메모
- 휴지통 (삭제 후 복구)

<br/>

### 동기화 및 디바이스
- 멀티 디바이스 동기화
- 오프라인 모드 (PWA)
- 크로스 플랫폼 여부 (웹만 / 모바일 포함)

<br/>

### 보안 및 프라이버시
- 메모 잠금 (비밀번호/생체인증)
- 종단간 암호화
- 공개/비공개 설정

<br/>

### 협업 및 공유
- 메모 링크 공유 (읽기 전용)
- 실시간 공동 편집
- 댓글

<br/>

### 외부 연동
- 캘린더 연동 (일정 있는 메모 자동 표시)
- Notion / Evernote에서 마이그레이션(import)
- Markdown / PDF export
- 웹 클리퍼 (브라우저 확장으로 웹페이지 스크랩해서 메모화)
- 개발자용 API 공개

<br/>

### 생산성 및 개인화
- 다크모드 / 테마
- 단축키 커스터마이징
- 오늘의 메모 대시보드 (오늘 쓴 메모, 오늘 할 일 등)
- 습관/기록 트래커 (매일 쓰는 메모용)

<br/>

### 데이터 관리
- Export / Import (백업 목적)
- 메모 통계 (작성 빈도, 자주 쓰는 태그 등)

> 참고
> - 협업/공유, 멀티 디바이스 동기화는 인프라 복잡도가 크게 올라가는 영역
> - 웹 클리퍼, 오늘의 메모 대시보드는 차별화 포인트 대비 구현 부담이 낮은 편
