## 요즘 뜨는 웹 폰트 조사

### 영문
- **Inter** — 가장 대중적인 UI 폰트, 가독성 좋고 자간 튜닝이 잘 되어있음 (Figma, Linear 등 다수 사용)
- **Geist** (Vercel) — 모던하고 깔끔한 느낌, 최근 스타트업 랜딩페이지에서 급증
- **Söhne / General Sans** — 프리미엄한 느낌의 SaaS 랜딩에 자주 쓰임
- **Satoshi** — 지오메트릭 산세리프, 마케팅 페이지에 인기
- **Space Grotesk** — 약간 개성 있는 느낌, 테크/크립토 계열 서비스에 많이 사용

<br/>

### 한글 지원
- **Pretendard** — 사실상 한국 웹서비스 표준급, 가변 폰트라 굵기 조절 자유롭고 무료
- **SUIT** — Pretendard와 비슷한 포지션, 조금 더 부드러운 인상
- **Paperlogy** — 최근 스타트업 계열에서 자주 보이는 폰트

<br/>

### 코드/모노스페이스
- **JetBrains Mono**, **Geist Mono** — 개발자 대상 서비스에 고려 가능

<br/><br/>

## Pretendard vs SUIT 비교

| 항목 | Pretendard | SUIT |
|---|---|---|
| 제작자 | orioncactus (개인 개발자) | 만8000개 스튜디오 (SUNN) |
| 라이선스 | OFL (무료, 상업적 이용 가능) | OFL (무료, 상업적 이용 가능) |
| 베이스 | 애플 산돌고딕Neo 계열 영감, 여러 시스템 폰트 조합 재해석 | 자체 디자인, Pretendard보다 후발주자로 차별화 시도 |
| 굵기(weight) | 9단계, 가변 폰트 지원 | 9단계, 가변 폰트 지원 |
| 인상 | 각지고 또렷함, 중립적 — "표준" 느낌 | 곡선이 살짝 더 부드럽고 둥글둥글함 |
| 영문/숫자 | 무난한 산세리프 | 자체 제작, 숫자가 좀 더 슬림하고 세련됨 |
| 채택 사례 | 압도적으로 많은 한국 웹/앱 서비스 표준 | 최근 신생 서비스·디자인 시스템에서 채택 증가 중 |
